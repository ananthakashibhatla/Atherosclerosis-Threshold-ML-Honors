# Iteration 01 — Threshold-Logistic Regression Foundations

## Purpose

Iteration 01 establishes the mathematical, data-science, and interpretable machine-learning foundation of the honors research project.

The threshold-logistic differential equation is the **source of the simulated system**, not an afterthought. The data pipeline and regression models are evaluated against behavior generated by this known mathematical model.

## Central Research Question

> Using simulated atherosclerotic plaque trajectories generated from a research-informed threshold-augmented logistic differential equation, can simple linear and logistic regression models predict future plaque burden and future progression regime, and does adding additional trajectory-derived predictors improve performance?

## Iteration Workflow

1. Define the problem.
2. Document the literature foundation.
3. Define and analyze the threshold-logistic ODE.
4. Generate controlled synthetic trajectories.
5. Inspect, clean, and preprocess the data.
6. Perform exploratory data analysis.
7. Engineer a small set of interpretable features.
8. Fit simple linear regression.
9. Add predictors and compare multiple linear regression.
10. Fit simple logistic regression.
11. Add predictors and compare multiple logistic regression.
12. Compare performance, especially near the threshold and under measurement noise.
13. Document limitations, faculty feedback, and revisions.
14. Sign off Iteration 01 before expanding model complexity.

## Definition of Done

Iteration 01 is complete when the repository contains a reproducible dataset-generation workflow, documented preprocessing and EDA, interpretable regression baselines, model-comparison results, an iteration retrospective, and faculty review/sign-off.

## Scientific Boundary

This is a computational modeling study. The simulated threshold `T` is not a validated clinical cutoff and the exact threshold-augmented ODE is not claimed to be a clinical law.
